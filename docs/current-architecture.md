# Current architecture

`BetterPanelComponent` applies saved tree tools in order: Trim, Simplify, Flatten, Reverse. With all tools off, it forwards Grasshopper's typed input tree unchanged. `PanelTreeOperations` copies paths and branch lists before changing structure, preserving typed goo and upstream data. Trim removes trailing path indices, merging coincident branches in source order; fully trimmed paths become `{0}`. The component captures a presentation snapshot of the output once per solution. `SnapshotCapture` caches primitive summaries and keeps live goo references in the component for full-value copying on the Rhino UI thread.

`BetterGhPanel.Core` owns immutable snapshots, query options, stable source positions, filtering, cancellable sorting, and statistics. Histogram values are calculated once when requested; native views use scalar statistics. Row IDs can differ from positions in `Snapshot.Rows`; query `RowIds` contains positions, not those IDs.

One `PanelSession` per component owns the current snapshot, copied options, and the published result. Queries run against managed snapshots in the background. Cancellation and request numbers reject obsolete results before UI publication. Query revisions synchronize controls even when an equal reset must clear an unsubmitted draft. Equal options do not trigger another scan.

`BetterPanelAttributes` draws the canvas and handles tree tools, row interaction, scrolling, inline editing, and resizing. Tree tools expire the solution, record undo, clear stale branch selections, and mark the definition modified. Search, filters and sorting affect only the view; Reset view leaves tree tools active. The context menu can reset the tree tools separately. `CanvasMenu` owns dropdown lifetime and paging; `CanvasPanelSize` owns dimension validation and presets. Selection and full-value lookup use snapshot positions with ownership checks. The modeless inspector and its row view were removed in `0.1.3-beta.1`.

Width and height are canonical saved settings. New panels use 360 × 360; existing dimensions and size presets retain their original behavior. Preset check marks are derived from dimensions. Serialization retains the legacy `PanelSize` key, and reads it as a fallback when dimensions are absent. Missing tree tool settings default to disabled, preserving older definitions' output. Document closure releases sessions; a tab switch closes the editor while retaining the snapshot.

The managed test runner covers query behavior and pure canvas menu/size logic without Rhino. The separate Windows Rhino smoke harness checks host integration, tree transformations and combinations, upstream preservation, saved settings, legacy defaults, output recomputation, and native UI interactions. Its test adapter contains the reflection needed to inspect the loaded `.gha` and host-owned controls. The review image in `docs/images/panel-tree-tools.png` comes from the actual native Objects renderer with a solved sample tree and illustrative grid/wires.

Packaging builds `net48` and `net7.0`, derives manifest versions from `Directory.Build.props`, and stages only the expected runtime payloads. CI runs on Windows and Mac; it does not launch Rhino. The archived browser study in `prototype/` is a visual reference with an independent sample-data engine. `docs/architecture.md` preserves the original proposal.
